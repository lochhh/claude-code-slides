# Introducing Claude Agent in JetBrains IDEs

[Ivan Moiseev](https://blog.jetbrains.com/author/ivan-moiseev-jetbrains-com)

TL;DR:

The new Claude Agent is now seamlessly integrated into JetBrains IDEs via the AI chat and included in the JetBrains AI subscription. No extra plugins, no extra subscriptions – just advanced AI coding assistance built on Anthropic’s Agent SDK, which powers Claude Code, right inside your IDE. The new agent leverages Anthropic models, including the freshly released **Claude 4.5 Sonnet.**

## A new milestone in JetBrains’ AI journey

Earlier this year, we added Junie, the smart coding agent by JetBrains, as part of the unified JetBrains AI subscription – introducing agentic features into our developer environments. We set our sights on extensibility as the next milestone – bringing developers access to the latest AI models and agents.

Today, thanks to our partnership with Anthropic, we are announcing that our Claude Agent is now available in JetBrains IDEs as one of the tools for agentic workflows. This marks the first third-party agent integrated into JetBrains IDEs and the beginning of our multi-agent ecosystem.

## Why Claude Agent

Built on the [Claude Agent SDK](https://docs.claude.com/en/api/agent-sdk/overview), JetBrains’ Claude Agent leverages the same foundational building blocks that make Claude Code effective – including context management, file operations, tool calls, and code execution – all within JetBrains IDEs.

> *The Claude Agent SDK represents our commitment to making it easy to build sophisticated agents on Claude. Developers can now leverage Claude’s intelligence, with a powerful agent framework, right out of the box. JetBrains gets this vision, and their use of the SDK to build their native Claude Agent shows what’s possible when you combine world-class developer tools with frontier AI capabilities.”*
>
> ***— Cat Wu, Product Manager, Claude Code, Anthropic***

Until now, most developers accessed Claude Code from the command line. With Claude Agent, you can access its advanced reasoning and coding capabilities directly inside your JetBrains IDE. The integration brings three key benefits:

**Native IDE integration** – JetBrains’ Claude Agent runs directly inside the JetBrains AI chat, with full access to IDE capabilities through the JetBrains MCP server.

**Frictionless setup** – no plugins, no extra logins, no standalone tools. Claude Agent is ready to use instantly for all JetBrains AI subscribers.

**One unified workspace** – JetBrains’ Claude Agent is delivered as a part of our AI chat interface, streamlining your workflow and reducing context switching.

## How Claude Agent helps you code in JetBrains IDEs

JetBrains’ Claude Agent can analyze your project, plan multi-step tasks, and execute them with IDE-level awareness. Here’s what you can do:

* **Work across multiple files**: See suggested changes with diff previews in the editor, and review them side by side before accepting or discarding.
* **Stay in control with approval-based operations**: Claude Agent won’t edit files or run commands without your approval (unless you enable *Brave* mode).
* **Use** ***Plan*** **mode** to preview a step-by-step implementation strategy, separating “thinking” from “doing” for more predictable workflows.
* **Manage context:** Add files, folders, or images as context so Claude Agent can provide more precise answers.

## Getting started

Claude Agent is included in the JetBrains AI subscription at no additional cost. Getting started is simple:

1. Open the AI chat in your JetBrains IDE.
2. Choose the *Claude Agent* option in the chat.
3. Start prompting – Claude Agent will be downloaded and initialized automatically.

If you don’t have AI Assistant enabled yet, follow [these steps to get started](https://www.jetbrains.com/help/ai-assistant/installation-guide-ai-assistant.html).

## Looking ahead

The integration of Claude Agent into our agentic AI offering reflects JetBrains’ philosophy of leveraging the best innovations – whether developed internally or with strategic partners like Anthropic – to give developers access to best-in-class tools and real choice.

Claude Agent is just the beginning. Our vision is an open, multi-agent ecosystem within JetBrains IDEs, delivered in a seamless, unified experience.

Which other agents would you like to see integrated next? We’d love to hear your ideas.
