# Agentic Workflow Pattern

![scooter-lacroix](https://avatars.githubusercontent.com/u/47616017?v=4)

Implements a standardized multi-agent pipeline to orchestrate complex software development tasks through autonomous sub-agents.

The Agentic Workflow Pattern is a sophisticated orchestration layer for Claude Code that breaks down complex implementation tasks into a structured five-stage pipeline: Research, Planning, Validation, Implementation, and Review. By utilizing background sub-agents and file-based state management, it ensures high-quality code output while maintaining a lean main conversation context. This skill is essential for large-scale codebase changes where precision, test-driven development (TDD), and cross-verification against documentation and best practices are required.
